# Lewisham Dog Fouling Evidence Log

Public evidence log for dog-fouling incidents recorded in Lewisham.

The website is designed for GitHub Pages. `index.html` contains the incident data and page layout; evidence photographs are referenced from an `images/` folder.

The log records first-seen date/time, location, observations, and photographs where available. Follow-up checks can be added later to record whether an incident is still present, partly cleared, or cleared, while keeping those review details collapsible in the public view.
